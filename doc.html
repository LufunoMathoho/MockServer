📚 Media Library API

This API allows you to view, add, update, and delete media items like movies, series, and songs.

Endpoints:

  • GET /movies – Get all movies
  • GET /series – Get all series
  • GET /songs – Get all songs
  • POST /movies, /series, /songs – Add a new item
  • PUT /movies, /series, /songs – Update an item by title
  • DELETE /movies?title=Inception – Delete an item by title

Request Body Format (JSON)

POST / PUT body example:

{
  "title": "Inception",
  "genre": "Sci-Fi",
  "year": 2010
}

Notes:

  • title is required for updating or deleting an item.
  • All data is stored in mediaLibrary.json.
